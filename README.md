# Agent Eval Lab

A small, inspectable evaluation lab for an assistant with memory, email, and calendar tools.

The central question: **Can a more explicit agent policy improve task completion without increasing unintended actions?**

This project measures behavior in a synthetic, in-memory environment. It is not a benchmark of commercial assistants or evidence of production performance. Published offline examples validate the harness; real model evaluations are reported separately.

Implementation and reproducibility instructions are being added in staged commits.
